# 🎮 RoChat — Внешний чат для Roblox

Внешний чат-оверлей для Roblox, работающий как отдельное приложение поверх игры.
Позволяет общаться с другими пользователями RoChat на одном сервере или во всём плейсе, обходя блокировку встроенного чата.

---

## ✨ Возможности

- **Серверный чат** — сообщения видят только игроки на вашем сервере
- **Глобальный чат** — сообщения видят все игроки данного плейса (на всех серверах)
- **Авто-определение сервера** — чат автоматически синхронизируется с текущим сервером Roblox
- **Оверлей поверх Roblox** — окно отображается поверх Roblox, но другие приложения могут его перекрывать
- **Перемещение и закрепление** — перетаскивание по экрану + кнопка закрепления 📌
- **Изменение размера** — потяните за правый нижний угол
- **Прозрачный режим** — переключение прозрачности 🌙
- **Тёмная тема** — стильный интерфейс, не отвлекающий от игры

## 📦 Установка

### Требования
- Python 3.10+
- Windows 10/11

### 1. Клонируйте / скачайте проект

### 2. Установите зависимости сервера
```bash
cd server
pip install -r requirements.txt
```

### 3. Установите зависимости клиента
```bash
cd client
pip install -r requirements.txt
```

---

## 🚀 Запуск

### Шаг 1: Запустите сервер-ретранслятор
```bash
cd server
python server.py
```
По умолчанию сервер запускается на `0.0.0.0:8765`.

Для изменения хоста/порта:
```bash
python server.py --host 127.0.0.1 --port 9000
```

### Шаг 2: Запустите клиент
```bash
cd client
python main.py
```

### Шаг 3: Войдите в аккаунт
1. В окне входа вставьте ваш `.ROBLOSECURITY` cookie
2. Укажите адрес сервера (по умолчанию `ws://localhost:8765`)
3. Нажмите **Войти**

---

## 🔑 Как получить .ROBLOSECURITY cookie

1. Откройте **roblox.com** в браузере и войдите в аккаунт
2. Нажмите `F12` → вкладка **Application** (Chrome) или **Storage** (Firefox)
3. В разделе **Cookies** → `https://www.roblox.com` найдите `.ROBLOSECURITY`
4. Скопируйте значение cookie

> ⚠️ **ВАЖНО:** Cookie — это ключ к вашему аккаунту. Никому его не передавайте!
> RoChat хранит cookie **только в оперативной памяти** и не сохраняет на диск.

## 🏗️ Архитектура

```
┌─────────────┐        WebSocket        ┌─────────────────┐
│  Клиент #1  │ ◄──────────────────────► │                 │
│  (PyQt5)    │                          │  Relay Server   │
└─────────────┘                          │  (WebSocket)    │
                                         │                 │
┌─────────────┐        WebSocket        │  Маршрутизация: │
│  Клиент #2  │ ◄──────────────────────► │  place_id →     │
│  (PyQt5)    │                          │    глобальный   │
└─────────────┘                          │  place_id +     │
                                         │  job_id →       │
┌─────────────┐        WebSocket        │    серверный    │
│  Клиент #N  │ ◄──────────────────────► │                 │
│  (PyQt5)    │                          └─────────────────┘
└─────────────┘

Каждый клиент также опрашивает Roblox API
для определения текущего сервера игрока.
```

### Как работает определение сервера

1. Клиент авторизуется через `.ROBLOSECURITY` cookie
2. Каждые 5 секунд опрашивается `presence.roblox.com` для получения `placeId` и `gameId`
3. `placeId` — идентификатор игры (плейса)
4. `gameId` — идентификатор конкретного сервера (инстанса)
5. Глобальный чат объединяет всех по `placeId`
6. Серверный чат объединяет только по `placeId` + `gameId`

## 🌐 Развёртывание сервера

Для использования с друзьями сервер можно развернуть на VPS:

```bash
# На VPS
python server.py --host 0.0.0.0 --port 8765
```

Клиенты подключаются по адресу:
```
ws://ваш-ip:8765
```

Для продакшена рекомендуется использовать обратный прокси (nginx) с SSL:
```
wss://ваш-домен/ws
```

## ⚡ Известные ограничения

- Работает только на **Windows** (из-за Win32 API для оверлея)
- Требует запущенный relay сервер
- Чат работает только между пользователями RoChat (не интегрирован с игровым чатом Roblox)
- Presence API может иметь задержку в несколько секунд
